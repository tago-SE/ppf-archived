# GraphQL highlights

in resolvers the depth must always be 0, the graphql server will then resolve IDs to object based on query

currently by default resolvers are returning only documents with _state: "published", if draftMode it ignores document status.


### Current PayloadCMS limitations
1. We can only generate/make custom types and resolvers. It is not possible to alter types and resolvers generated by Payload.
2. It is not possible to override GraphQL server and Payload GrapthQL configuration is limited. This is not a big issue, however, it is not possible to override schame in a way to define custom directives - https://www.apollographql.com/docs/apollo-server/schema/directives#custom-directives
